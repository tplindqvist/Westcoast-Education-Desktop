# Westcoast Education – Desktop

Skrivbordsapp i Avalonia för att administrera kurser, studenter och lärare.
Inlämningsuppgift 3 – .NET Cloud Development.

## Funktioner
- Lista, lägga till, ändra och radera kurser
- Lista, lägga till och radera studenter
- Lista, lägga till, ändra och radera lärare, inklusive kompetensområden

## Kom igång
- Kräver .NET 10 SDK.
- Kräver API-nyckel och adress till RestDb.

## Struktur
- **WestcoastEducation.Core:** modeller, services och HTTP-kommunikation
- **WestcoastEducation.Desktop:** vyer, ViewModels, dialogruta och stilar
